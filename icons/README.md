# gorak file icons

SVG masters supplied in gorak-file-icons.zip, with light and dark variants for
16 px language icons. W4GL is green, WML blue, metadata amber, and field defaults
purple. Metadata and field-defaults assets are reserved; they do not register
language associations.

The project ork derives from `docs/branding/gorak-icon-small.svg` in
[dougwhite/gorak](https://github.com/dougwhite/gorak), blob
`8dfd2bcd50d86849ec795bbb6b26a6fb0efceabb`. The four document symbols were drawn
for gorak; no OpenROAD product artwork was copied. Assets are self-contained
SVG geometry without fonts, external references or raster images.
